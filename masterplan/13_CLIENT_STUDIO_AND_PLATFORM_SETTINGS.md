# 13 — Client, Studio and Platform Settings

## Player settings
- Graphics quality preset and manual controls.
- Resolution and display mode.
- Audio volume by category.
- Input sensitivity and key bindings.
- Controller support.
- Language.
- Accessibility options.
- Download/storage location where safe.
- Network/data usage preferences.
- Privacy and social controls.
- Notification preferences.

## Studio settings
- Theme and editor layout.
- Autosave interval.
- Backup location.
- Build configuration.
- Runtime channel.
- Default test player count.
- MUTE formatting and lint preferences.
- Keyboard shortcuts.
- Asset import defaults.
- Git integration and credential management.
- Diagnostics consent and upload settings.

## Poko Mod settings
- Moderator notification preferences.
- Review queue filters.
- Test environment defaults.
- Safe evidence viewing settings.
- Session/security management.
- Audit export permissions.

## Accessibility
- UI scaling.
- High contrast.
- Reduced motion.
- Color-independent status indicators.
- Keyboard navigation.
- Screen-reader labels where supported.
- Subtitle/caption support.
- Remappable controls.
- Audio cues with visual equivalents where practical.

## Device support
Define minimum CPU, GPU/API, RAM, storage and network expectations per app. Do not promise all Windows 11 devices are supported without testing. Android 11+ is a minimum OS target, not a performance guarantee.

## Offline behavior
Clearly distinguish:
- Fully offline game.
- Online-only game.
- Offline-capable game with optional cloud features.

Offline play should not fail merely because an optional social or cloud service is unavailable.
