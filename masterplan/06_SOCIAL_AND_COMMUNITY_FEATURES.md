# 06 — Social and Community Features

## Player relationships
- Friend requests with configurable privacy.
- Followers/following as a separate, optional relationship.
- Block and mute.
- Recent players list with privacy controls.
- Online status visibility controls.
- Report user from profile, chat and game session.

A block should prevent direct contact and invitations where possible. Explain what blocking does and does not prevent.

## Messaging
For a child-accessible platform, do not launch unrestricted direct messaging without a mature safety design. Options include:
- Friends-only messaging.
- Predefined safe phrases for younger accounts.
- Rate limits and spam detection.
- User block/report controls.
- Image/file sharing disabled initially.
- Link handling and external URL restrictions.
- Privacy-preserving moderation and retention rules.

Chat moderation should consider context and false positives. Severe child-safety cases need a restricted escalation process.

## Player-created content
If players can upload text, images, decals, audio or models, treat each upload surface as user-generated content. Apply file limits, scanning, reporting, review or post-publication controls appropriate to the risk.

## Profile customization
- Avatar, biography and selected games.
- Optional creator links.
- Badges earned through platform activities.
- Profile themes from approved assets.
- No public display of private contact details.

## Community events
Potential future features:
- Scheduled group events.
- Official Poko events.
- Game jams.
- Creator showcases.
- Build competitions.
- Event reminders and participation badges.

Events need clear time zones, cancellation handling and reporting tools.

## Safety defaults
- Private-by-default contact settings for younger users where required.
- No location sharing.
- No sharing of real-world contact details in public profile fields.
- Report and block controls visible at point of interaction.
- Rate limits on friend requests and messages.
