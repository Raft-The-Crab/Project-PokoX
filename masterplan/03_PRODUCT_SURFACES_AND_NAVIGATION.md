# 03 — Product Surfaces and Navigation

## PokoX Player
Suggested main navigation:
- Home
- Discover
- Search
- Friends
- Groups
- Messages (if enabled)
- Library
- Profile
- Notifications
- Settings

Game detail page:
- Title, icon, creator/team, description and screenshots.
- Content labels.
- Supported devices and game modes.
- Player count/status where reliable.
- Play button and favorite button.
- Report game and block creator controls.
- Version and update notes where useful.

Player library:
- Installed games.
- Recently played.
- Favorites.
- Offline-available games.
- Downloads and updates.
- Storage management.

## Shared design system
Use consistent typography, icons, spacing, color tokens, status labels and error patterns. Do not use color alone to communicate severity. Support keyboard navigation and screen readers where platform UI frameworks permit.

## Navigation principles
- Keep the most frequent action one or two clicks away.
- Preserve unsaved work when switching panels.
- Make destructive actions require confirmation.
- Display loading, empty, offline, permission-denied and error states explicitly.
- Avoid exposing internal service names or third-party implementation details to ordinary players.
