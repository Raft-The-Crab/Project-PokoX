# PokoX System-First Development Plan

Revision: 2026-11-11

This pack replaces the earlier slice-by-slice roadmap with a system-first, sequential-subsystem approach. Build the engine and runtime foundations first, then networking, MUTE, packages, backend, dedicated hosting, publishing/moderation, remaining platform services, end-to-end integration, and finally polished Player/Studio/Mod UI.

Temporary Dear ImGui tools, CLI utilities, test clients, headless harnesses and automated tests are encouraged throughout development. They are engineering tools, not final product UI.
