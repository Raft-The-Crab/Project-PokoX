# 07 — Audio, Input, Animation and Character

Audio: miniaudio behind a Poko interface; device discovery, voices, streaming, categories and device-loss handling.

Input: SDL2 behind an abstraction; keyboard/mouse and controller first; touch mapping later; rebinding and focus-loss behavior.

Animation: skeletons, clips, sampling, blending/state machines, events, root-motion policy and retargeting.

Character: R6 default, named accessory attachment points, rig-independent interfaces and later R15 support. Verify any third-party rig/model licence before reuse.

Exit gate: character moves, animates, equips accessories and plays audio in a test scene.
