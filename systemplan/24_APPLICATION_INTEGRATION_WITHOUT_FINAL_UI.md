# 24 — Application Integration Without Final UI

Use CLI, automated end-to-end tests, test clients, ImGui developer panels, API test collections and headless harnesses.

Prove workflows:
1. Build project and run offline.
2. Build/verify/launch `.pkx`.
3. Build `.pkxx`, start and register server.
4. Join using ticket.
5. Submit game for review.
6. Execute in Review Runtime.
7. Reject, retry and approve exact package hash.
8. Discover/download approved game.
9. Update while old approved release remains live.
10. Report user/game and process case.
11. Revoke server credential.

Replace mock adapters one at a time and run failure scenarios. Exit gate: critical journeys work end-to-end without final visual UI.
