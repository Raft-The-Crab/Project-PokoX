# 20 — Moderation, Review Runtime and Inspector

Policy: every update reviewed; suitability uses labels; human makes final decision; one appeal; four formal reviews; broad creative allowance but no sexually explicit/adult content or child sexual exploitation. Fictional blood/gore may be allowed under policy and labels; labels never excuse prohibited content.

Run untrusted submissions in disposable isolated Review Runtime, never directly on moderator workstation. No production credentials; separate test accounts/data; resource limits; restricted network; timeout/cleanup; package hash/runtime recorded; evidence access audited.

Inspector: hierarchy, assets, character/rig, animation timeline, MUTE source/static analysis/debugger, service permissions, network events, physics, UI/audio, storage, profiler and logs.

Suspected child sexual abuse material/grooming requires restricted specialist handling and legally reviewed evidence/reporting workflow.

Exit gate: moderator can inspect/execute safely, record findings, approve/reject and have privileged actions audited.
